Privacy Policy — DevTools Pro

Last updated: 2026-09-15

Data Collection

DevTools Pro does not collect, transmit, or share any personal data. All inspection and analysis happens locally in your browser. Every tool is free; there is no account, no license and no payment.

Permissions Explained

DevTools Pro requests no access to websites at install. It touches a page only when you open the extension on that tab and pick a tool.

  • activeTab: when you click the toolbar button on a tab, this grants temporary access to that one tab so the tool you pick can inspect it.
  • scripting: injects the inspector (the on-page overlay and panel) into that tab — and its same-origin frames — when you pick a tool. Nothing is injected into any page before that.
  • storage: saves your preferences (theme, compact panel) and recent eyedropper colours locally on your device.

What the tools do with a page

  • Inspection tools (CSS, colours, fonts, spacing, measure, grid, accessibility, CSS variables, page assets, page meta) read the page's styles and structure locally to show them to you.
  • Live Edit changes the page you are on — text, spacing, colours, font size — locally and temporarily. Changes are never saved or sent anywhere and disappear when the page reloads.
  • Screenshots are captured from the visible tab and saved as a file you download and/or copied to your clipboard. They are never uploaded.

What the extension does NOT do

  • Does not collect analytics or usage data
  • Does not use cookies or tracking pixels
  • Does not transmit any data to external servers
  • Does not access your browsing history
  • Does not run on any page until you pick a tool there

Data Storage

All data is stored locally on your device using the browser's storage API. No data is stored on external servers.

Changes to This Policy

If this privacy policy changes, the updated policy will be posted here and the "last updated" date will be revised.

Contact

If you have questions about this privacy policy, please file an issue on the extension's support page.
