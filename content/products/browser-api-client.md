A REST client and API tester that opens in a full browser tab. Build a request, press Send, read the response — and nothing is lost when you click away. No desktop app to install, no account to create, no cloud sync you didn't ask for. Every feature is free.

## Build and send

- **Any HTTP request** — GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, to any API, without CORS in the way
- **Request tabs that keep your work** — drafts are saved as you type and survive a reload
- **Every body type** — JSON, URL-encoded form, multipart with file uploads, raw text, binary file, GraphQL
- **Authentication** — Bearer token, Basic, API key (header or query), and OAuth 2.0 (client credentials, or authorization code with PKCE)

## Read responses clearly

- Status, timing and size; pretty JSON with a collapsible tree and find-in-body
- Image and sandboxed HTML preview; hex view and download for binary
- The full redirect chain and `Set-Cookie` headers
- Network failures named with their cause — DNS, refused connection, TLS certificate, timeout
- Server-Sent Events shown live as they arrive

## Test, chain and run

- **Tests without scripts** — check status, headers, JSON paths, body text and response time on every response
- **Request chaining** — copy a token or id from one response into `{{variables}}` for the next request
- **Collection runner** — run a collection or folder in order, see pass/fail per request, re-run only the failures

## Stay organized

- Collections with folders, history grouped by day, and environments for dev, staging and production with secret values masked
- **Import** a cURL command, an OpenAPI 3 / Swagger 2 spec, a Postman v2.1 collection or environment, or a HAR file
- **Export** collections to Postman v2.1, and code snippets for cURL, JavaScript fetch, Node.js axios, Python requests, Go, PHP, C# and HTTPie
- Keyboard first: Cmd/Ctrl+Enter sends, Cmd/Ctrl+S saves, `?` lists every shortcut. Light and dark themes.

## Private by design

No account, no sign-in and no pairing with a desktop app — ever. No tracking and no analytics. Your requests, tokens, collections and history are stored only in your browser, and requests go straight from your browser to the API you choose. See the [privacy policy](/privacy/browser-api-client) for exactly what each permission is used for.
