> **Retired 2026-09-15.** Tailwind CSS Lookup is no longer maintained and is being withdrawn from the Chrome Web Store. Its class database predates Tailwind CSS v4, and it never found enough users to justify a rebuild. The source stays on GitHub, read-only, for anyone who wants to fork it.

Search any Tailwind CSS class to see its CSS output. Inspect elements to discover Tailwind classes on any page.

## Features

- Inspect any element to see its Tailwind classes
- Search any Tailwind class to see the generated CSS
- Reverse lookup: paste CSS to find the matching Tailwind utility
- Built for Tailwind v3 classes
- Light and dark themes
